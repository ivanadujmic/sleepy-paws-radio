Privacy Policy

Last updated: 8 November 2026

Sleepy Paws Uploader is a private tool used only by the owner of the YouTube channel Sleepy Paws Radio. It uploads the channel's own videos, titles, descriptions and thumbnails to that channel. It is not offered to anyone else.

YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app uses

  • Access to the signed-in YouTube channel, to upload videos and set thumbnails.
  • The channel's name and ID, to confirm it uploads to the right channel.

The app does not collect, sell or share any personal data. It does not use analytics or cookies. The sign-in token is stored only on the owner's own computer and is never sent anywhere other than Google.

Removing access

Access can be revoked at any time on the Google security settings page. Deleting the local token file also removes stored data.

Hosting

This website is hosted on GitHub Pages. GitHub may log visitor IP addresses for security, as described in the GitHub Privacy Statement.
